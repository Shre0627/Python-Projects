Python Projects

This repository showcases a diverse collection of my Python projects, each designed to explore different applications of the language and demonstrate my programming skills. The projects are organized into individual directories, providing detailed documentation and instructions for usage.

Project List:
1) Basic Calculator: A simple calculator application that performs basic arithmetic operations like addition, subtraction, multiplication, and division. The implementation receives user input and utilizes functions, loops, conditional statements, lists, and match statements to achieve its functionality. To handle potential errors I used try and except blocks to ensure invalid errors or unexpected errors do not crash the program.  

2) Password Validator: A password validator program where the user creates their username and password and the program validates the password to ensure it meets the requirements and is a strong password so their account will not get hacked. This application recieves user input and utilizes functions, loops and conditional statements to achieve it's functionality. To handle potential errors I used try and except blocks to ensure invalid errors or unexpected errors do not crash the program.

3) Selection Sort and Bubble Sort Algorithms: Developed Selection Sort and Bubble Sort algorithms from scratch, allowing users to input a list of numbers to be sorted efficiently within seconds. This implementation leverages key programming constructs such as nested loops, try-except blocks for error handling, conditional statements, and list manipulation.
